# Experiment 1: Working with Widgets and Layouts

## Aim
To design and develop a Flutter application that displays a list of fruit items using `Row`, `Column`, `Container`, `Card`, and `ListView` widgets, and to create reusable custom widgets to organize the user interface effectively.

## Concepts & Widgets Covered
- **Row**: Aligns fruit information horizontally (e.g., fruit icon, details, price/action).
- **Column**: Vertically stacks title, scientific name, and nutrient badges.
- **Container**: Provides margins, padding, decorative backgrounds, and custom borders.
- **Card**: Provides an elevated container with rounded corners and shadows for material design.
- **ListView.builder**: Dynamically renders scrollable lists of fruit cards efficiently.
- **Custom Reusable Widgets**:
  - `FruitCard`: Modular card widget encapsulating fruit layout logic.
  - `NutrientBadge`: Compact badge widget for calorie count, seasonality, and origin.
